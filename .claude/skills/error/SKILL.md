---
name: error
description: Diagnostica un fallo que el mensaje de error no explica. Informa, planifica o corrige, según lo que se pida.
---

1. Fija el síntoma, lo esperado, cómo reproducirlo y qué no se puede tocar.
2. Sigue el camino de ejecución (con Graphify si está activo) y abre solo lo necesario.
3. Separa hechos, hipótesis y comprobaciones. Cambia una variable cada vez. Sin permiso, no cambies
   código para probar una hipótesis arriesgada. Los scripts temporales van fuera del proyecto.
4. Según lo pedido: diagnóstico, informa y para; plan, usa `crear-plan`; corrección, arregla lo
   mínimo y comprueba que el fallo no vuelve.
5. Si te bloqueas, di qué evidencia tienes y qué decisión falta.
